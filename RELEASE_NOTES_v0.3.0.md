# PromptHalo 0.3.0 Alpha

PromptHalo turns five high-value prompts into a macOS muscle-memory wheel.

## Highlights

- Hold Left `Option`, choose `1–5`, release, and insert a full prompt
- Chinese and English interface
- Five substantial starter prompts in both languages
- Local-first prompt storage with no account or cloud dependency
- Universal build for Apple silicon and Intel Macs

## Install

1. Download and unzip `PromptHalo-v0.3.0-Alpha-macOS-universal.zip`.
2. Move `PromptHalo.app` to `/Applications`.
3. Control-click the app and choose **Open** if macOS blocks the first launch.
4. Allow PromptHalo in **System Settings → Privacy & Security → Accessibility**.

## Alpha warning

This build uses a local development signature and is not Apple-notarized. It is published early for Build in Public feedback.

Known issues:

- First-run permission recovery can still be confusing.
- Rapid repeated invocations are not yet fully reliable in every app.
- Prompt insertion does not yet cancel when the foreground app changes.

Please report reproducible issues through GitHub Issues without including private prompt or clipboard content.
